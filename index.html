项目说明

数据、方法与设计依据

说明本项目如何从 BACI 国际贸易数据出发，构造依赖指标，并转化为多视图交互式可视分析系统。

Research Question

世界各国如何依赖中国制造？

本系统聚焦全球供应链中的结构性进口依赖：不同国家在制造业进口中， 对中国制造形成了怎样的依赖关系？这种依赖是否集中在少数国家、少数产品类别或特定年份之中？

2007-2024 时间跨度
国家 × 产品 × 年份 分析对象
7 个交互模块 最终展示形态

理论依据

Nested Model

项目遵循 Tamara Munzner 的 Nested Model：先界定供应链依赖问题， 再抽象为国家、产品、年份和贸易流任务，最后选择 3D 地球、热力矩阵、桑基图和供应链星系图进行表达。

数据来源

CEPII BACI

数据来自 CEPII BACI Version 202601，覆盖 2007-2024 年国际贸易记录。 字段包括出口国、进口国、HS6 产品、贸易额和数量。本项目默认以 CHN 作为中国大陆口径。

分析目标

可解释探索

系统不只展示总量，而是帮助观众回答三个问题：谁更依赖中国制造、依赖集中在哪些产品、 哪些产品在全球供应链中更值得关注。

核心指标

Metric definitions
依赖度 D D(j,k,t) = V(China,j,k,t) / sum_i V(i,j,k,t) 表示某国某类产品进口中来自中国的比例。
综合依赖 CDI CDI(j,t) = sum_k [D(j,k,t) * W(j,k,t)] 按产品重要性加权后，衡量国家总体依赖水平。
来源集中 HHI HHI(j,k,t) = sum_i share(i,j,k,t)^2 衡量进口来源是否集中在少数供应国。
产品脆弱性 0.35D + 0.25HHI + 0.25Importance + 0.15ChinaShare 用于探索高依赖、高集中、高重要性的重点产品。

可视化设计逻辑

Seven views
全球总览用 3D 地球观察国家依赖水平和中国制造流向。
国家故事拆解单个国家的长期变化、结构特征和核心依赖类别。
依赖热力图比较国家与产品类别之间的依赖强弱。
贸易流向用桑基图解释中国制造流向哪些区域、国家或收入组。

扫雷游戏把风险识别、标记置信度和防御工具转化为互动体验。

数据处理流程

Pipeline
  1. 读取 BACI 原始 CSV，并筛选 2007-2024 年数据。
  2. 统一国家代码、HS6 产品代码和商品范围口径。
  3. 计算总进口额、来自中国进口额、依赖度、HHI 和产品重要性。
  4. 聚合到国家、区域、收入组、分析大类、分析细类和专题标签。
  5. 导出静态 JSON / CSV，由前端按模块加载并渲染。

商品分类口径

Scope system

系统支持全部商品、初级商品、加工食品与烟草、制造品、特殊商品五类范围。 同时保留 HS 原始章节、项目派生分析大类和分析细类，以及半导体、电池、医疗健康等专题标签。

首页默认展示制造品 HS28-96 和分析大类，便于观众先看到最清晰的宏观结构。

适用边界与参考资料

Limitations & sources

进口依赖不等同于真实断供概率。现实风险还受到库存、本国产能、替代技术、企业合同、 政策环境、物流条件和转口贸易等因素影响。因此，本项目中的综合风险和脆弱性指标主要用于可视化探索与相对比较。
