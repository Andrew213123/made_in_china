# 课堂展示脚本

## 1. 开场

本项目关注全球供应链中的结构性进口依赖。核心问题是：世界各国在哪些制造品上对中国形成较高依赖，这种依赖是否集中在少数产品、少数国家或少数年份中。

## 2. 3D 地球总览

打开首页后，先展示国家热力标记和中国到全球的贸易弧线。说明颜色表示依赖程度，弧线表示中国制造流向主要国家。

操作：

1. 播放 2007–2024 年份时间轴。
2. 调整依赖阈值，只保留高依赖国家。
3. 切换到电子电气或绿色制造品。

讲解重点：空间分布用于发现区域差异，年份变化用于观察依赖是否上升或下降。

## 3. 国家案例对比

点击 Vietnam、India、Germany、United States。

讲解重点：

- Vietnam：电子电气和机械设备依赖较高。
- India：机械设备和绿色制造品值得关注。
- Germany：依赖程度不一定最高，但中间品结构有解释价值。
- United States：趋势变化体现依赖不是静态排名。

## 4. 国家产品矩阵

进入矩阵页，横轴是产品类别，纵轴是国家，颜色表示依赖度、HHI 或脆弱性。

讲解重点：矩阵能同时比较国家和产品，避免只看单个国家详情。

## 5. 桑基图

进入流向页，说明结构是中国到产品类别，再到国家。

讲解重点：桑基图适合展示 Top N 流向，不能直接展示全部贸易流，否则可读性下降。

## 6. 产品脆弱性靶盘

进入靶盘页，点击锂电池或光伏组件。

讲解重点：越靠近中心表示综合脆弱性越高，点大小表示贸易规模，边框表示战略产品。该视图把高依赖、高集中、高重要性的产品推到视觉中心。

## 7. 方法与局限性

进入说明页，解释 BACI 数据、依赖度、HHI、产品脆弱性指数。

最后强调：本系统衡量的是贸易结构中的进口依赖，不等同于真实断供风险。真实风险还取决于库存、本国产能、替代技术、企业合同和政策环境。
