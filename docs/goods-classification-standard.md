# 商品分类标准

本项目基于 BACI HS07 六位商品编码构建可视化分析体系。分类遵循“官方 HS 章节口径 + 分析型大类/小类”的双层结构，兼顾可追溯性与图表可读性。

## 一、分类层级

```text
L0 hs_section
L1 hs_chapter
L2 analysis_major
L3 analysis_minor
L4 hs6_code
```

此外保留：

```text
scope
topic_tag
```

其中：

- `scope`：控制分析范围
- `analysis_major`：主图和矩阵默认展示的大类
- `analysis_minor`：下拉框、Top 类别贡献、细分类矩阵使用的小类
- `topic_tag`：跨章节专题标签，一个 HS6 可以拥有多个标签

## 二、Scope 标准

| Scope ID | 中文名称 | HS 范围 |
| --- | --- | --- |
| `all_goods` | 全部商品 | HS01–97 |
| `primary_goods` | 初级商品 | HS01–15、HS25–27 |
| `processed_primary_goods` | 加工食品与烟草 | HS16–24 |
| `manufactures` | 制造品 | HS28–96 |
| `special_goods` | 特殊商品 | HS97 |

默认分析范围：

```text
manufactures
```

## 六、专题标签

`topic_tag` 不互斥，一个 HS6 可拥有多个标签：

- `green_manufacturing`
- `battery_chain`
- `solar_pv_chain`
- `ev_chain`
- `semiconductor_chain`
- `medical_health`
- `industrial_equipment`
- `infrastructure_materials`
- `consumer_goods`
- `strategic_transport`

## 七、前端使用建议

- Globe 左侧筛选：优先使用 `analysis_minor`
- Matrix 默认：使用制造品相关 `analysis_major`
- Matrix 细分模式：切换到 `analysis_minor`
- Country 右侧 Top 5：按 `analysis_minor` 贡献排序
- Flow 页面：默认显示 Top 6 类别
- Target 页面：使用 `HS6 + analysis_minor + topic_tag`
