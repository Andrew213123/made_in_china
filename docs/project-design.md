# 中国制造依赖网络：项目设计说明

英文题名：China Manufacturing Dependency Network: Visualizing Structural Dependence in Global Supply Chains

## 研究问题

本项目聚焦一个有限但具有现实意义的问题：世界各国在哪些制造品上对中国形成较高进口依赖，这种依赖是否集中在少数产品、少数国家或少数年份中。

系统不试图展示全球贸易全貌，而是围绕国家、产品、年份三类核心维度构建可交互探索界面。当前数据时间尺度设为 2007–2024 年，与本地下载的 BACI HS07 V202601 年度文件保持一致。

## 理论框架

项目采用 Tamara Munzner 的 Nested Model 组织设计逻辑：

1. 领域问题：全球供应链中的结构性进口依赖。
2. 数据与任务抽象：国家、产品、年份、贸易额、依赖度、来源集中度。
3. 视觉编码与交互：3D 地球、国家产品矩阵、桑基图、产品脆弱性靶盘、国家详情卡。
4. 算法实现：Python 预处理 BACI 数据，前端读取静态 JSON/CSV，部署到 GitHub Pages。

## 核心指标

国家产品中国依赖度：

```text
D(j,k,t) = V(China,j,k,t) / sum_i V(i,j,k,t)
```

国家总体中国制造依赖指数：

```text
CDI(j,t) = sum_k D(j,k,t) * W(j,k,t)
```

进口来源集中度：

```text
HHI(j,k,t) = sum_i share(i,j,k,t)^2
```

产品脆弱性指数：

```text
Vulnerability =
0.35 * 中国依赖度
+ 0.25 * 进口来源集中度
+ 0.25 * 产品进口重要性
+ 0.15 * 中国全球供给占比
```

该指标是贸易结构层面的相对脆弱性，不等同于真实断供风险。

## 视图分工

3D 地球总览：回答哪些国家总体上更依赖中国制造，以及高依赖国家是否存在空间集中。

国家产品依赖矩阵：回答一个国家依赖哪些制造品，不同国家的依赖结构是否相似。

中国制造流向桑基图：回答中国制造主要通过哪些产品类别流向哪些国家或区域。

产品脆弱性靶盘：回答哪些产品同时具有高依赖、高集中和高重要性特征。

国家详情卡：回答某一国家依赖结构是什么，近年来依赖趋势如何变化。

## 交互设计

年份变化会同步更新地球热力、贸易弧线、详情趋势、矩阵、桑基图和靶盘。

点击国家会聚焦地球相机、更新右侧详情，并在矩阵中形成对应分析上下文。

点击产品类别会改变地球着色含义，并过滤桑基图和靶盘。

调整阈值会隐藏低依赖国家，并在靶盘中过滤低脆弱性产品。

## 课程展示重点

展示时建议先用 3D 地球建立空间感，再用国家详情进入具体案例，随后用矩阵和靶盘证明“结构性依赖”不只是单一国家排名，而是国家、产品和进口来源集中度共同作用的结果。
